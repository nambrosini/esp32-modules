# KY-003 vs KY-035 Hall Sensor

Both are Hall effect sensor modules, but they use different sensor types and serve different purposes.

## KY-003 (Digital Hall Sensor)

- **Output**: Digital (HIGH/LOW)
- **Sensor chip**: Typically uses the **A3144** (or similar) Hall effect switch
- **Behavior**: Outputs LOW when a magnetic field of sufficient strength is detected, HIGH otherwise (or vice versa depending on wiring) — it's a threshold/switch type sensor
- **Use case**: Detecting presence/absence of a magnet, counting rotations (e.g., RPM sensing), door/lid open detection, simple proximity triggers
- **Pins**: Usually 3 pins — VCC, GND, Signal (digital)

## KY-035 (Analog Hall Sensor)

- **Output**: Analog (variable voltage)
- **Sensor chip**: Typically uses a linear Hall sensor like the **49E** or similar
- **Behavior**: Outputs a voltage proportional to the strength (and polarity) of the magnetic field — it can detect not just presence but intensity and direction of the field
- **Use case**: Measuring magnetic field strength, detecting how close a magnet is (not just on/off), current sensing setups, more nuanced motion/position detection
- **Pins**: Usually 3 pins — VCC, GND, Signal (analog, needs an ADC pin on your microcontroller)

## Summary Table

| Feature | KY-003 | KY-035 |
| --- | --- | --- |
| Output type | Digital | Analog |
| Sensor type | Switch (threshold) | Linear (proportional) |
| Detects | Presence/absence of field | Field strength/intensity |
| Typical ADC needed | No | Yes |
| Common use | RPM counting, on/off detection | Distance estimation, field strength measurement |

## Notes for ESP32 (Rust)

- The **KY-035** needs to be read from an ADC-capable GPIO pin (e.g., using `esp-hal`'s ADC driver).
- The **KY-003** just needs a regular digital GPIO input, which is simpler to wire up in `embedded-hal`.
